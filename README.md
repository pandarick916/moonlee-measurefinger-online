# moonlee-measurefinger-online
## ⚖️ Open Source & License

This online widget for measuring fingernail width was independently developed by **[MOONLEE](https://moonleehome.com)**, an independent press-on nails brand. 

Recognizing its high practicality and its ability to solve a real pain point for users when measuring sizes, we have decided to fully open-source this tool to support developers, peers, and the community.
